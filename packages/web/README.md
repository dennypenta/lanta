# @lanta/web

SolidJS frontend for Lanta.

## Tech Stack

- **Framework**: SolidJS
- **Router**: Solid Router
- **UI Components**: Kobalte UI
- **Styling**: Tailwind CSS

## Available Scripts

### `bun dev`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `bun run build`

Builds the app for production to the `dist` folder.
